# GitHub'a yükleme

1. ZIP dosyasını bilgisayarda açın.
2. Hasan'ın GitHub hesabında yeni bir depo oluşturun: `aya-disaster-management-assistant`.
3. Açıklama: `Accessible disaster preparedness, wearable sensing and occupancy monitoring - student engineering research.`
4. Portföyü herkesin görmesi için Public seçin. Pakette mevcut oldukları için yeni README veya .gitignore oluşturmayın. Ayrıca yeni bir lisans seçmeyin; ekip hakları `RIGHTS.md` dosyasında açıklanmıştır.
5. Depoda `uploading an existing file` veya `Add file > Upload files` seçin.
6. Bu dosyanın ve `README.md` dosyasının bulunduğu klasörün **içeriğini**, dosya ve alt klasör yapısını koruyarak sürükleyin. Dıştaki `aya` klasörünü veya ZIP'in kendisini yüklemeyin.
7. `.github`, `.gitignore` ve `.gitattributes` dosyalarını da ekleyin. macOS Finder'da gizli dosyaları göstermek için Command + Shift + nokta; Windows'ta Dosya Gezgini'nin gizli öğeleri gösterme seçeneğini kullanabilirsiniz.
8. Kayıt açıklaması: `Add AYA research portfolio, prototype sources and documentation`.
9. Yükleme sonrası ana sayfada tanıtım ve prototip fotoğrafının göründüğünü, klasörlerin açıldığını kontrol edin. `Actions` sekmesinde doğrulama iş akışının sonucunu görebilirsiniz.

Paket, tek seferlik tarayıcı yüklemesindeki 100 dosya sınırının altındadır ve her dosya 25 MiB'tan küçüktür. Paket içindeki `secrets.example.h` dosyaları boş yerel yapılandırma örnekleridir. Kendi bağlantı bilgilerinizi eklediğiniz `secrets.h` dosyalarını yüklemeyin.
